## What the example does

* Calibrates the same table with every interpolation method the library
  provides: piecewise linear, log-linear, log-log, monotone cubic (PCHIP) and
  monotone cubic over the logarithm of the raw value
* Prints the interpolated values of all methods side by side
* Extrapolates the values outside the calibration range

## Wiring

No wiring is required.
